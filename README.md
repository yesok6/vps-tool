# ⚡ VPS-Tool 综合运维与网络代理工具箱

> 专为 Linux VPS 打造的一站式轻量运维脚本。兼顾极致网络性能、抗封锁代理、安全加固与 IP 质量审计，面向小白提供全自动。
持续更新中。
---

## 🌟 核心特性与亮点

- 🛡️ **安全加固，防失联闭环**：系统补丁与时间校准支持确认后执行；修改 SSH 端口与密钥认证时内置严格拦截与防失联指引，UFW/firewalld 自动准备规则；已记录的防火墙规则会在卸载时按工具记录清理，但云平台安全组规则不会由本工具替换或删除。
- 🚀 **前沿协议，免买域名**：精选 **VLESS-Reality** 与 **Hysteria 2** 协议，后台并发实测毫秒级握手延迟，自动优选无 CDN 干扰的大厂伪装（Apple、Mozilla 等），一键直出客户端分享链接。
- 🏎️ **压榨极限，内核调优**：保留 **BBRv3 Max 激进内核**、666shen **网卡软中断全核均衡**、IPv4 优先解析与百万级连接句柄，提供暴躁冲速率与生产级自适应两种调优模式；其中 BBRv3 Max 属于第三方底层内核变更，安装前会明确提示且不会承诺自动回滚。
- 📦 **懒人福音，交钥匙工程**：模块 4 支持一键自动化流水线（系统更新 ➔ 网络调优 ➔ 协议部署 ➔ 防火墙提示）；协议阶段自动选择可用端口，不再卡在交互式端口输入。流水线涉及系统升级、内核/网络参数及协议部署，关键风险步骤仍会进行二次确认。
- 🔍 **安全体检，用完即焚**：集成星标最高的 IPQuality 欺诈分、流媒体/AI 解锁与三网回程路由；独创**硬件防死机哨兵**（内存/磁盘低配预警），测试后自动销毁垃圾文件。
- 🔄 **透明可控，无痕卸载**：所有功能均明确标注 `[可完全撤销]`、`[部分可撤销]`、`[不可逆]` 与 `[安全保留]`；支持在线更新，并提供按工具记录执行结果的**系统清理与变更恢复报告**。

## 📁 项目目录结构

```text
vps-tool/
├── install.sh              # 主入口、菜单、安装/更新/清理
├── lib/
│   └── common.sh           # 公共函数、状态记录、备份与回滚
├── modules/
│   ├── security.sh         # 系统安全、SSH、防火墙
│   ├── protocol.sh         # VLESS-Reality / Hysteria 2
│   ├── optimize.sh         # 网络优化、Swap、BBR 等
│   ├── apps.sh             # 一键综合流水线
│   └── ip_test.sh          # IP 质量与网络测试
├── tests_smoke.sh          # 基础语法与关键逻辑烟雾测试（需 root）
└── README.md
```

资源检查说明：系统升级优先看“可用内存”而不是总内存。可用内存达到 256 MiB 以上通常直接进入升级；128–255 MiB 会根据磁盘余量建议 256/512/768/1024 MiB Swap，创建后始终至少保留 1 GiB 根分区空间；低于 128 MiB 则更谨慎处理。Swap 是磁盘提供的虚拟内存缓冲，不能替代真实 RAM。

启动时的远端版本检查可通过环境变量关闭：

```bash
VPS_TOOL_VERSION_CHECK=0 bash install.sh
```

关闭版本检查不会关闭“8. 在线更新”功能；只是不在每次进入主菜单时自动查询远端版本。启动时的远端版本结果默认缓存 15 分钟，减少网络等待。
已安装到 `/opt/vps-tool` 的本地版本启动时不会静默重新拉取整套代码；首次通过远程安装命令启动时才会同步本地工具包。需要更新时请使用菜单 **8. 在线更新**，模块缺失时才会触发一次补偿同步。

## 🚀 快捷运行

只需在你的 Linux VPS 终端中粘贴并执行以下命令即可启动：

### 官方主线（推荐）

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yesok6/vps-tool/main/install.sh)
```

### 国内 / 拥堵加速镜像

```bash
bash <(curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/yesok6/vps-tool/main/install.sh)
```

> **提示**：首次运行后，脚本会自动注册快捷指令。以后在终端任意位置直接输入 `vps` 即可秒开主菜单！

### 🔥 防火墙端口管理

- 模块 1 → 5 负责防火墙基线；模块 1 → 6 可查看当前已放行端口，并显示常见用途。
- 模块 1 → 4 可启用 SSH 防爆破保护（Fail2Ban）；默认 10 分钟内失败 5 次封禁 1 天，并显示当前保护端口。查看状态后可分别选择：1. 当前封禁 IP 总数；2. 近 5 分钟新封禁 IP（重复合并）；3. 当前封禁 IP 详细。状态页顶部同时显示当前保护端口。
- Fail2Ban 会优先使用当前 SSH 端口，并把本次 SSH 来源 IP 加入忽略列表；停用本工具 jail 时只删除本工具配置，不强制卸载 Fail2Ban。
- 可直接新增 `1–65535` 的 TCP/UDP 端口，或按编号禁用放行规则；当前 SSH 端口禁止从这里误关闭。
- SSH 端口迁移成功后，会同步关闭本工具能够安全识别的旧端口防火墙规则；无法确认归属的规则会保留并提示手动处理。

### 🧯 系统升级前资源检查

- 模块 1 → 1/2 在执行更新前会检查可用内存和根分区空间。低资源环境会先警告；低于保守安全阈值时停止执行，避免升级过程中因内存或磁盘不足失败。
- 这些阈值是运维保护线，不是发行版官方最低要求。

### 🔥 防火墙与流水线说明

- 本工具只管理自己记录的 UFW/firewalld 规则；卸载时仅删除这些已记录规则。模块 1 的 firewalld 基线放行属于安全保留项，不会因为卸载模块而强制撤销。
- 云厂商控制台中的安全组、网络 ACL 或外部防火墙规则不属于本工具管理范围，卸载时不会主动删除。
- 模块 4 的自动化流水线会尽量使用非交互参数；但涉及系统升级、底层内核或高风险网络调整时仍可能要求二次确认。用户取消某个关键确认时，该步骤视为“未执行”，流水线会立即停止，不会继续执行后续步骤。

### 🔐 SSH 端口迁移与防失联说明

模块 1 → 选项 3 现在提供四种 SSH 相关操作，并且在删除旧端口前都要求完成明确的安全验证：

- **1. 修改 SSH 端口（保留旧端口）**：默认模式。新旧端口会同时监听。工具会明确提醒你必须先新开终端，通过新端口实际登录成功；之后再次进入模块 1 → 3 → 选项 2，才能手动删除旧端口。
- **2. 删除已验证的旧 SSH 端口**：必须同时检测到旧端口和新端口仍在监听，并且当前运行工具的 SSH 会话本身就是通过新端口登录。任一条件不满足，都不会执行删除；删除成功后会同步清理本工具自己创建的旧端口防火墙放行。
- **3. 查看成功登录 SSH 的 IP**：读取 SSH 服务最近 5000 条日志；重复 IP 自动合并，并按最近一次成功登录时间由近到远排列，结果分页显示，避免一次性刷满终端。
- **4. 放弃本次迁移并恢复原 SSH 端口**：用于迁移状态卡住或用户决定不继续迁移时。工具会使用本次迁移保存的原始 SSH 配置回退；如果当前会话来自新端口，回退可能立即断开当前连接，因此会再次警告并要求确认。

> ⚠️ 云厂商安全组、网络 ACL 或外部防火墙仍需提前放行新端口。本工具不提供自动删除旧端口；确认新端口登录成功后，请使用选项 2 手动删除旧端口。若迁移状态卡住，可使用选项 3 回退。

### 🧯 SSH 迁移回退

- SSH 端口迁移开始时会单独保存本次迁移的原始 SSH 配置。若迁移状态因中断而卡住，可进入模块 1 → 3 → 4 放弃迁移并恢复原端口。
- 如果当前会话来自新端口，回退会停止新端口监听，当前会话可能立即断开；操作前请确保旧端口仍可从外部重新连接，或准备云控制台/VNC。

### 🔥 防火墙状态检查

- 第一次进入模块 1 → 5 时，工具会先展示当前防火墙状态以及准备放行的 SSH/HTTP/HTTPS 规则，再要求确认；确认后才执行配置。模块 1 → 6 可随时查看、增加或关闭端口规则。
- 如果 UFW/firewalld 已经启用，后续再次进入模块 1 → 5 会直接展示当前已经放行的端口/服务。只有发现基线规则缺失时才会询问是否补充，不会重复出现“立即启用”提示；已启用的 UFW 只补缺失规则，不会重置你现有的默认入站/出站策略。

### 📝 可恢复性备注传统

- **可完全撤销**：只有在工具保存了原始状态、并能可靠恢复到修改前状态时才使用这个标记。
- **部分可撤销/安全保留**：涉及 SSH 防失联、防火墙基线、云安全组或外部系统时，只恢复本工具能可靠控制的本机部分，其余保留并明确提示。
- **不可逆/不可恢复**：系统升级、第三方底层内核等无法由本工具可靠恢复的变更，不标记为“可完全撤销”。
- **工具不会管理的内容**：云厂商安全组、网络 ACL、外部防火墙以及用户自行创建的同名资源，不会因为卸载而强制删除。

### SSH 与 Fail2Ban 联动

- Fail2Ban 以当前 `sshd` 实际生效端口为准。
- SSH 迁移期间若旧、新端口同时存在，F2 会同时保护两个端口。
- 删除旧 SSH 端口后，F2 会同步收缩到新端口；本工具创建的旧端口防火墙放行也会同步清理。
- [部分可撤销] F2 只管理本工具创建的 jail，不会接管用户现有的其它 Fail2Ban jail。
