# ⚡ VPS-Tool 综合运维与网络代理工具箱

> 专为 Linux VPS 打造的一站式轻量运维脚本。兼顾极致网络性能、抗封锁代理、安全加固与 IP 质量审计，面向小白提供全自动。
持续更新中。
---

## 🌟 核心特性与亮点

- 🛡️ **安全加固，防失联闭环**：系统补丁与时间校准支持确认后执行；修改 SSH 端口与密钥认证时内置严格拦截与防失联指引，UFW/firewalld 自动准备规则；已记录的防火墙规则会在卸载时按工具记录清理，但云平台安全组规则不会由本工具替换或删除。
- 🚀 **前沿协议，免买域名**：精选 **VLESS-Reality** 与 **Hysteria 2** 协议，后台并发实测毫秒级握手延迟，自动优选无 CDN 干扰的大厂伪装（Apple、Mozilla 等），一键直出客户端分享链接。
- 🏎️ **压榨极限，内核调优**：保留 **BBRv3 Max 激进内核**、666shen **网卡软中断全核均衡**、IPv4 优先解析与百万级连接句柄，提供暴躁冲速率与生产级自适应两种调优模式；其中 BBRv3 Max 属于第三方底层内核变更，安装前会明确提示且不会承诺自动回滚。
- 📦 **懒人福音，交钥匙工程**：模块 4 支持一键自动化流水线（系统更新 ➔ 网络调优 ➔ 协议部署 ➔ 防火墙提示）；协议阶段自动选择可用端口，不再卡在交互式端口输入。流水线涉及系统升级、内核/网络参数及协议部署，关键风险步骤仍会进行二次确认。
- 🔍 **安全体检，用完即焚**：集成星标最高的 IPQuality 欺诈分、流媒体/AI 解锁与三网回程路由；独创**硬件防死机哨兵**（内存/磁盘低配预警），测试后自动销毁垃圾文件。
- 🔄 **透明可控，无痕卸载**：所有功能均明确标注 `[可完全撤销]`、`[部分可撤销]`、`[不可逆]` 与 `[安全保留]`；支持在线更新，并提供按工具记录执行结果的**系统清理与变更恢复报告**。

## 📁 项目目录结构

```text
vps-tool/
├── install.sh              # 主入口、菜单、安装/更新/清理
├── lib/
│   └── common.sh           # 公共函数、状态记录、备份与回滚
├── modules/
│   ├── security.sh         # 系统安全、SSH、防火墙
│   ├── protocol.sh         # VLESS-Reality / Hysteria 2
│   ├── optimize.sh         # 网络优化、Swap、BBR 等
│   ├── apps.sh             # 一键综合流水线
│   └── ip_test.sh          # IP 质量与网络测试
├── tests_smoke.sh          # 基础语法与关键逻辑烟雾测试（需 root）
└── README.md
```

启动时的远端版本检查可通过环境变量关闭：

```bash
VPS_TOOL_VERSION_CHECK=0 bash install.sh
```

关闭版本检查不会关闭“8. 在线更新”功能；只是不在每次进入主菜单时自动查询远端版本。
已安装到 `/opt/vps-tool` 的本地版本启动时不会静默重新拉取整套代码；首次通过远程安装命令启动时才会同步本地工具包。需要更新时请使用菜单 **8. 在线更新**，模块缺失时才会触发一次补偿同步。

## 🚀 快捷运行

只需在你的 Linux VPS 终端中粘贴并执行以下命令即可启动：

### 官方主线（推荐）

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yesok6/vps-tool/main/install.sh)
```

### 国内 / 拥堵加速镜像

```bash
bash <(curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/yesok6/vps-tool/main/install.sh)
```

> **提示**：首次运行后，脚本会自动注册快捷指令。以后在终端任意位置直接输入 `vps` 即可秒开主菜单！

### 🔥 防火墙与流水线说明

- 本工具只管理自己记录的 UFW/firewalld 规则；卸载时仅删除这些已记录规则。模块 1 的 firewalld 基线放行属于安全保留项，不会因为卸载模块而强制撤销。
- 云厂商控制台中的安全组、网络 ACL 或外部防火墙规则不属于本工具管理范围，卸载时不会主动删除。
- 模块 4 的自动化流水线会尽量使用非交互参数；但涉及系统升级、底层内核或高风险网络调整时仍可能要求二次确认。用户取消某个关键确认时，该步骤视为“未执行”，流水线会立即停止，不会继续执行后续步骤。
